# LimSur Catálogo Web

Proyecto listo para subir a Vercel o Netlify.

## Cómo publicarlo en Vercel
1. Entrá a https://vercel.com
2. Creá una cuenta o iniciá sesión.
3. Tocá **Add New Project**.
4. Subí esta carpeta o conectala con GitHub.
5. Vercel detecta Vite automáticamente.
6. Tocá **Deploy**.
7. Te da un link para poner en Instagram.

## Comandos locales
npm install
npm run dev
npm run build
